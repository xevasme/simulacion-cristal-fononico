# Archivos del Proyecto General

Directorio destinado a almacenar la documentación base que guía la simulación numérica.

**Contenido:**
* Documento consolidado del anteproyecto general.
* Artículos científicos de referencia (Kushwaha, Pennec, Vasseur, etc.).
* Literatura complementaria sobre acústica, métodos de elementos finitos y estado sólido.
