# Modelo Infinito

Este directorio contiene los scripts y cálculos relacionados con el modelo teórico del cristal fonónico infinito. 

**Objetivos de esta fase:**
* Aplicación del teorema de Bloch.
* Determinación de los vectores de onda a lo largo de los puntos de alta simetría en la zona irreducible de Brillouin.
* Cálculo computacional de la estructura de bandas y determinación teórica de los bandgaps acústicos.
